# SENTRY — S0 Data Foundation

This directory contains the synthetic ground-truth dataset for the SENTRY
Maintenance Troubleshooting Copilot evaluation harness.

> **Important:** All files here are synthetic and authored by the SENTRY team.
> No real OEM documentation has been reproduced. All sensor values, work-order
> records, and equipment specifications are fictional.

## Regenerating the Data

All generators use a fixed seed (`SEED = 42`). Running any script twice produces
byte-identical output.

```bash
# 1. Convert Markdown corpus to PDF
python scripts/generate_corpus.py

# 2. Generate healthy + faulted sensor snapshots
python scripts/generate_sensors.py

# 3. Generate maintenance work-order history
python scripts/generate_history.py

# 4. Validate that scenario YAMLs reference real corpus headings
python scripts/validate_scenarios.py
```

## Sensor Baselines (`baselines.yaml`)

Defines nominal, warn, and alarm thresholds for all 9 sensors across both
asset classes. Source is `oem` for all entries (all values from the fictional
OEM specifications in the manuals).

| Sensor | Unit | Notes |
|---|---|---|
| vibration_rms | mm/s | Overall RMS from bearing housings |
| bearing_temp_de | C | Drive-end bearing housing temperature |
| bearing_temp_nde | C | Non-drive-end bearing housing temperature |
| motor_current | A | RMS phase current |
| discharge_pressure | bar | Gauge pressure at discharge flange |
| flow_rate | m3/h | Volumetric flow (process flow meter) |
| oil_level_pct | % | Bearing housing oil level (sight glass) |
| rpm | rpm | Shaft rotational speed |
| suction_pressure | bar | Gauge pressure at suction flange |

## What This Stage Does NOT Build

This is the S0 data-foundation stage only. The following are explicitly out of scope:

- Parsing, chunking, or embedding of the corpus (S1)
- Deviation calculation or evidence engine logic (S2)
- Retrieval or query planning (S3)
- Anomaly model training or inference (S4)
- LLM synthesis or guardrail layer (S5)
- API, UI, or observability components (S6, S7, S8)
- Evaluation harness logic (S9)
- Database schema, migrations, or ORM code
- Any write path to hardware, PLCs, or SCADA
